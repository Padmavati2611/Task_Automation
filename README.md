# 📁 Task Automation (File Organizer using Python)

## 📌 Description
This project is a Python-based task automation system that organizes files automatically. It scans a folder, identifies file types, and moves them into categorized folders like Images, Videos, and Documents. This helps in maintaining a clean and structured file system.

---

## 🚀 Features
- Automatically detects file types
- Moves files into respective folders
- Supports images, videos, and documents
- Reduces manual effort
- Simple and beginner-friendly

---

## 🛠️ Technologies Used
- Python
- OS module
- File Handling

---

## 📂 Input
A folder containing mixed files:
- `.jpg`, `.png` → Images  
- `.mp4`, `.avi` → Videos  
- `.pdf`, `.docx` → Documents
**EX: Downloads/
   photo1.jpg
   video1.mp4
   report.pdf 
---
**Output
Downloads/
   Images/
      photo1.jpg

   Videos/
      video1.mp4

   Documents/
      report.pdf
